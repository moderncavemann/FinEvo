# ICAIF 2026 submission checklist

- [ ] FinEvo is not under review at another archival venue, or written chair
      guidance confirms EGRM eligibility.
- [ ] All EGRM scientific cells have terminal receipts and full ITT coverage.
- [ ] Negative/no-go results are retained and corresponding claims narrowed.
- [ ] Paper uses current ACM `sigconf` with `anonymous` and is at most eight
      pages including figures and references.
- [ ] There is no supplement or appendix dependency.
- [ ] Author names, acknowledgements, repository URLs, metadata, and PDF
      properties are anonymized.
- [ ] Self-citations use third person.
- [ ] Final author list and order are correct before the initial CMT submission.
- [ ] One author can attend and present in Milan in person if accepted.
- [ ] Explicit source license is resolved before an independent code release.

Official source checked 2026-08-02:
https://icaif2026.org/call-for-papers.html
